# Customer Support Analytics: End-to-End Medallion Pipeline

## Project Purpose
I developed this project to demonstrate a complete data engineering lifecycle using the Medallion Architecture on Databricks. The pipeline manages the ingestion, transformation, and visualization of a dataset containing over 200,000 customer support tickets, simulating the challenges found in large-scale enterprise environments.

## Technical Architecture

### 1. Ingestion Layer (Bronze)
The primary challenge addressed in this layer was the handling of raw binary data. I implemented a pre-ingestion strategy to manage compressed ZIP files delivered to Databricks Volumes. 
- I utilized Python's native libraries to handle decompression within the landing zone.
- I configured Databricks Auto Loader (cloudFiles) to ensure incremental ingestion.
- I established checkpointing to maintain idempotency and prevent data duplication during job retries.

### 2. Transformation Layer (Silver)
In the Silver layer, I focused on data quality and structural integrity. I moved the raw data into a queryable, high-performance format.
- I performed schema enforcement and data type casting, converting strings into appropriate timestamps and integers.
- I implemented a deduplication logic based on unique ticket identifiers to ensure a single version of truth.
- I standardized column naming conventions to snake_case to facilitate cross-platform compatibility and SQL readability.

### 3. Analytics Layer (Gold)
The Gold layer represents the final business logic where data is aggregated for executive decision-making.
- I engineered key performance indicators (KPIs) such as Average Resolution Time and Customer Satisfaction Score (CSAT).
- I created dimensional aggregations by region, priority, and product category.
- I applied performance optimizations, including Z-Order indexing, to enhance query speed for downstream consumers.

## Business Insights and Visualization
I designed a comprehensive dashboard to visualize the support operation's performance. The dashboard focuses on operational efficiency and customer experience metrics, allowing stakeholders to identify bottlenecks in specific regions or product lines.

## Development Environment
- Platform: Databricks (Unity Catalog enabled)
- Language: PySpark and Python
- Storage: Delta Lake
- Data Source: [Customer Support Ticket Dataset](https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset)

## How to Deploy
1. Import the provided notebooks into a Databricks Workspace.
2. Configure a Volume named 'landing_tickets' within your Catalog.
3. Upload the source data to the landing volume.
4. Execute the notebooks in the defined sequence: Ingestion, Silver, and Gold.
